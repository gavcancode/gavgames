# GavGames third-party game credits

GavGames links to and embeds selected games from their original public browser-game pages. These games are not represented as GavGames originals. Each publisher continues to host its own game runtime. Availability, performance, and embed permissions can change if an upstream host changes its page or frame policy.

## Important notes

- The 2048 project identifies its original browser game and publishes its source under MIT.
- HexGL's upstream README says code and resources are MIT unless a file says otherwise. Keep any file-specific notices and credits.
- Hextris is GPL-3.0-or-later. If GavGames later copies or modifies and distributes its code, it must meet the GPL requirements, including providing corresponding source under the applicable terms.
- A Dark Room is MPL-2.0. If GavGames later copies or modifies and distributes covered files, comply with MPL source-disclosure requirements for those files.
- The 15 additional games are currently loaded from the public GitHub Pages site of sausi-7/games, whose repository declares MIT. They are a curated extra set, not all individually proven to be among the most-played games.
- This first integration embeds upstream pages; it does not copy their code or assets into GavGames. The games may open in a separate tab if an upstream host blocks embedding.
- Before self-hosting any third-party game, re-check the exact version's license, asset/audio/font notices, trademarks, and required attributions. Do not remove copyright or license notices.
